## Featured project

### Aspire College Platform

A public college website and an internal management portal in one system.

- **Public website:** about, academics, faculty, admissions, news and events, photo gallery, contact, and an "Ask Us" question box where visitors choose how much identity to share, attach files and follow the answer with a tracking code.
- **Management portal:** role-based access for Main Super Admin, Sub Admins with per-feature permissions, Principal (read-only), Class Representatives and Students. Includes admissions review, faculty and class management, website content editing, an activity log and an AI writing helper for drafting descriptions.
- **CR Connect module:** class-representative tools for attendance, reports and student concerns, now one part of the larger platform.
- **Built with:** React 18, TypeScript, Vite, Tailwind CSS, Supabase (Postgres with row-level security, Storage, Edge Functions) and Netlify.

[Live site](https://aspiretaunsa.netlify.app/) · [Source code](https://github.com/Zeeshan2770/Aspire-College)

## More projects

### CS Compass (CS-HUB)

A Class 12 Computer Science study platform where students learn a topic and practise it in the same place.

- **Learn:** the syllabus chapter by chapter, with lessons and cheat sheets.
- **Practise:** browser labs for Python, SQL, logic, subnetting and debugging, with nothing to install.
- **Test yourself:** practice quizzes and written-answer tests.
- **Study tools:** revision pages, bookmarks, search, a study planner and a focus timer.
- **Admin area:** lesson editor, question management and bulk import, grading of written answers, user management and an audit log.
- **Built with:** React, Vite and Supabase.

[Live site](https://cscompass12.netlify.app/) ·[Source code](https://github.com/Zeeshan2770/CS-HUB)

### Rewirs

An online course platform with manual enrollment and an admin panel.

- **Enrollment:** students submit a payment reference and an admin approves or rejects it.
- **Admin panel:** manage courses, lessons and students live, with no redeploy.
- **Security:** Row Level Security in Postgres does the real access control.
- **Built with:** Next.js, TypeScript, Tailwind CSS and Supabase.

[Live site](https://superchads.netlify.app/) ·[Source code](https://github.com/Zeeshan2770/Rewirs)
